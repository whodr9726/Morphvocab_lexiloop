# 逗号同义冗余精简任务（trim）· 规范提示词 v1（唯一权威版，禁改）

你是释义精简员。一批义项里用中文逗号挤了不止一个意思（用户报：pretty「adv. 相当地，蛮」设定只读 1 个义项却读出两个意思）。逐义判定并修复。

## 输入输出

- 输入：`<项目根>\tools\v2_batches\trim_NN.json`，格式 `{"词": ["全部义项"], ...}`（需处理的是含中文逗号"，"的义项）。
- 输出：`<项目根>\tools\v2_out\trim_NN.json`，UTF-8 JSON，**只含需要修改的词**：`{"词": ["修后完整 m 数组"], ...}`。
- 不需要修的词一个字不进输出；只准写这一个输出文件，严禁触碰 `webapp/` 目录任何文件。

## 判定与修复（对每个含逗号的义项）

1. **真同义冗余**（逗号两段意思相同、可互换，如「偏见，成见」「助手，帮手」「相当地，蛮」）→ **只留一个最自然、最常用的**：`n. 偏见`、`adv. 相当地`。选段标准：更常用、更贴该词主要用法；两段等同时选更短的。
2. **两个不同义挤一条**（如 arbitrary「任意的，武断的」——任意 vs 武断是两个真实义项）→ **拆成两条相邻义项**，各自带词性前缀，常见义在前：`"adj. 任意的","adj. 武断的"`。拆分后总义项数 +1，但每词最多拆 1 处、总条数 ≤10。
3. **互补搭配不是同义**（逗号/或连接的是同一动作的不同对象或语境，如「驱散人群或雾气」「召集起来或重振」类）→ **保持原样不动**（该词不进输出，或该义原样保留）。
4. **拿不准 → 不动**（保守原则）。

## 铁律

1. 未修义项逐字节保留；义项顺序除"拆分插入原位"外不得变动。
2. 词性标记保留原词性；格式全套合规：`词性. 中文`、白话 2~14 字、禁符号 `( ) （ ） [ ] 【 】 … ‥ = / 、 ; ；`。
3. 修复后该义项不得再含中文逗号（除非判定为第 3 类保持不动）。
4. 槽位形态保留：vt. 的"某X"槽、的/地、介词引出——精简时不得丢掉这些形态标记。

## 交付自查

- 输出 JSON 可解析；只含输入里的词；未修义逐字节一致；每词条数不变或 +1；修复义无逗号残留；无 vp. 新增。
