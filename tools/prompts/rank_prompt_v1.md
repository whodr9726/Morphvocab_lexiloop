# 单词常用度分档任务（rank）· 规范提示词 v1（唯一权威版，禁改）

你是词汇频率判定员。给每个英文词标注**常用度档位**，用于重排学习顺序（常用在前、生僻在后）。

## 输入输出

- 输入文件：`<项目根>\tools\v2_batches\rank_NN.json`，内容为英文词数组（NN 为你的批次号）。
- 输出文件：`<项目根>\tools\v2_out\rank_NN.json`，UTF-8 JSON：`{"词": "档位", ...}`。
- 每个输入词必须有输出，不多不少；只准写这一个输出文件，严禁触碰 `webapp/` 目录任何文件。

## 档位定义（按该词最常用义的日常使用频率）

| 档位 | 判据 | 直觉检验 |
|---|---|---|
| A1 | 日常生存与高频沟通：家庭、饮食、购物、出行、身体、情感、最基本动词形容词 | 张口就来，小学水平 |
| A2 | 常用社会生活：工作、学习、媒体、日常事务 | 每周都会说/听到 |
| B1 | 中频一般语料：新闻常见、受过教育者书面口语都常用 | 每月会遇到 |
| B2 | 中高频书面与半正式场合 | 读报常见，口语少用 |
| C1 | 学术、正式书面 | 论文/报告用语 |
| C2 | 专业术语、文学修辞 | 只有特定领域/文学里见 |
| D | 生僻词 | 母语者都少用，考试冷僻 |

## 判定规则

1. 按**最常用义**判档，不看生僻义。
2. 心里问一句：一个普通英语使用者（非专业）多久用/遇到一次这个词？用频率定档，不要因"我认识"而抬档，不要因"拼写难"而降档。
3. 复合派生词参照词根频率（happiness ≈ happy 的档）。
4. 拿不准时取**更低频的那档**（宁可生僻词早学晚学，不可高估常用度把生僻词排前）。
5. 档位只能是七个之一：A1、A2、B1、B2、C1、C2、D。

## 交付自查

- 输出 JSON 可解析；词集合与输入完全一致；档位字符串全部合法。
- 抽查 10 词自问频率问题，答案与所标档位一致。
