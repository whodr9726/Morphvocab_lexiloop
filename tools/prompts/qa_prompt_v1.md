# 释义质量复审任务（qa）· 规范提示词 v1（唯一权威版，禁改）

你是释义质检修复员。复审一批**曾被批量精简过的词条**：当时个别释义被错误处理成「两段文字无分隔粘连」（如「长见识的有教育意义」「重大的严重的」）或仍残留逗号挤义。逐义判定并修复。

## 输入输出

- 输入：`<项目根>\tools\v2_batches\qa_NN.json`，格式 `{"词": ["全部义项"], ...}`。
- 输出：`<项目根>\tools\v2_out\qa_NN.json`，UTF-8 JSON，**只含需要修改的词**：`{"词": ["修后完整 m 数组"], ...}`。
- 不需要修的词一个字不进输出；只准写这一个输出文件，严禁触碰 `webapp/` 目录任何文件。

## 判定（对每个义项，三类病灶）

1. **粘连**（两段完整释义文字直接拼接无任何分隔，念起来是两个意思）：同义两段 → 只留最常用的一段（`有教育意义的，长见识的` 类 → `adj. 有教育意义的`）；不同义两段 → 拆成两条相邻义项各带词性（条数 +1，每词最多拆 1 处，总条数 ≤10）。
2. **逗号挤义**（一条义项内用中文逗号并列两段）：同上判定——真同义留一段；不同义拆两条；**同一动作的不同对象/语境属互补（如「戳穿某物或撬开某门」的"或"式）→ 合法保留不动**。
3. **单段但明显电报感/不通顺**（此前批量处理的副产品）→ 改写成自然白话。

合法形态（不动）：单一自然短语；「或」连接的互补搭配；槽位形态完整（某X/的/地/介词引出）。

## 铁律

未修义逐字节保留；义项顺序除拆分插原位外不变；词性标记保留；白话 2~14 字；禁符号 `( ) （ ） [ ] 【 】 … ‥ = / 、 ; ；`；修复义不得残留中文逗号（除非属互补判定保留）；每词最多 +1 条。

## 交付自查

输出 JSON 可解析；只含输入词；条数不变或 +1；被修义无粘连无逗号残留；格式合规。
