# 及物槽位修复任务（slot）· 规范提示词 v1（唯一权威版，禁改）

你是动词形态修复员。一批 `vt.` 标签的动词释义没带宾语槽（某/某人/某物/某事），违反形态转译规范（vt.=及物，释义须带裸宾语槽）；部分还兼有电报感不白话。逐义修复。

## 输入输出

- 输入：`<项目根>\tools\v2_batches\slot_NN.json`，格式 `{"词": ["全部义项"], ...}`（需修的是其中 vt. 开头且不含"某"的义项）。
- 输出：`<项目根>\tools\v2_out\slot_NN.json`，UTF-8 JSON，**只含需要修改的词**，格式 `{"词": ["修后完整 m 数组"], ...}`。
- 不需要修的词一个字不进输出；只准写这一个输出文件，严禁触碰 `webapp/` 目录。

## 修复规则（按优先级）

1. **补槽为主**：该动词确为及物 → 释义补宾语槽并保持白话自然。
   例：`vt. 打` → `vt. 打某人或某物`；`vt. 喂` → `vt. 喂某人吃饭`；`vt. 接电话` → `vt. 接某电话`。
2. **电报感改写**：挤在一起的词拆成自然口语（同义并列用中文逗号）。
   例：`vt. 认为觉得` → `vt. 认为某事，觉得`；`vt. 画线描图` → `vt. 画，描绘某事物`。
3. **标签纠错（谨慎）**：vt. 明显标错才动——该义实际是纯不及物 → 改 `vi.` 且释义去槽化；实际是 v.+槽 常规形态 → 改 `v.`。没把握就不动标签只修文字。
4. **合法保留（不进输出）**：中文表达习惯上无槽也完全自然、且加槽反而不通的（如 `vt. 为产品做宣传` 这类介词引出式），保持原样。
5. 形态规范全套沿用：白话 2~14 字、禁符号 `( ) （ ） [ ] 【 】 … ‥ = / 、 ; ；`、vt. 义修后必须含"某"（除非标签改为 vi./v.）、其他词性的义一个字不许动、义项条数与顺序冻结。

## 交付自查

- 输出 JSON 可解析；只含输入里的词；未修义逐字节原样；修后 vt. 义含某（或标签已改）；条数与输入一致。
