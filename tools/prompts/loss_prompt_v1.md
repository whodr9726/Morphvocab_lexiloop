# 词义丢失修复任务（loss）· 规范提示词 v1（唯一权威版，禁改）

你是词义库修复员。词库 v2 重写时，部分词丢掉了旧库里真实常用的词性义（如 petition 丢了动词义"请愿"、forecast 丢了名词义"预报"）。你的任务是逐词判定并把真丢的常用义补回来。

## 输入输出

- 输入文件：`<项目根>\tools\v2_batches\loss_NN.json`，格式：
  `{"英文词": {"v1": ["旧库该词全部义项"], "cur": ["现库该词全部义项"], "miss": "丢的词性列表（逗号分隔）"}, ...}`
- 输出文件：`<项目根>\tools\v2_out\loss_NN.json`，UTF-8 JSON，**只包含需要补义的词**：
  `{"英文词": ["补全后的完整 m 数组", ...]}`
- 不需要补义的词：一个字都不许出现在输出里。
- 只准写这一个输出文件，严禁触碰 `webapp/` 目录任何文件。

## 判定（对每个 miss 词性）

- **补**：旧库该词性义在现代英语里真实常用——普通使用者会在日常/新闻/学术普通语料中遇到该词的这个用法。
  例：repair 丢 n.（汽车修理的"修理"是名词高频义）→ 补；forecast 丢 n.（天气预报 weather forecast）→ 补；auction 丢 v.（拍卖某物）→ 补。
- **不补**（该词不进输出）：旧库该词性义生僻、过时、或旧库本身标错。
  例：indirectly 标 adj 是脏数据；impractical 标 v 不是真实常用用法；lethal 的名词用法罕见。
- 拿不准时不补（保守）。
- **禁止补 vp.（介词动词）义**：vp 是独立工程类目（需映射表与音频联动），本轮一律不补。

## 补义格式（与词义工程全套规范一致）

1. 每条 = `词性. 中文`，词性 ∈ n./v./vt./vi./adj./adv./prep./conj./pron./aux./int./art./num.。
2. 中文 2~14 字口语白话，像给朋友解释；禁符号 `( ) （ ） [ ] 【 】 … ‥ = / 、 ; ；`；并列意思用中文逗号 `，`。
3. 形态转译规则（定稿工程）：
   - 及物动词带宾语槽：`v. 修理某物`、`v. 拍卖某物`（某/某人/某物/某事/做某事）
   - 纯不及物动词无槽自足：`vi. 咳嗽`
   - 形容词带"的"、方式副词带"地"（功能副词不带）
   - 名词用事物化裸名词短语：`n. 修理费` 类（禁止"某X"槽形态）
4. **旧义逐字节保留**：cur 里每一条（连标点空格都不变）必须出现在输出数组里；一条都不许删。
5. 新义按使用频率插入合适位置（数组 = 频率降序，跨词性交叉）：最常用就放开头，次常用插中间。
6. 每词补 1~3 条；补后该词总义项数 ≤10。

## 交付自查

- 输出 JSON 可解析；只含输入里的词。
- 每个输出词：cur 的每条原文在输出数组中逐字节存在；新增条数 1~3；无 vp. 新义；格式与禁符号合规。
