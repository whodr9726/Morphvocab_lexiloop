# 名词事物化任务（nn）· 规范提示词 v1（禁改；先读 AI交接/11 中文工程总规范）

用户需求（对称面）：动词已加动作感，名词义也要**去动作化、读起来像东西/事情**——一眼与动词区分。

- 输入：`<项目根>\tools\v2_batches\nn_NN.json`（`{"词": ["全部义项"]}`，其中含读起来像动作的名词义）。
- 输出：`<项目根>\tools\v2_out\nn_NN.json`，只含有修改的词（完整 m 数组）。

## 判定（对每个候选名词义）

1. **动作同形名词**（上升/下降/咳嗽/燃烧/衰落/跳水/慢跑 类——文本就是动词）→ 事物化改写：加事物标记或换名词性说法（升势、跌幅、咳嗽声、燃烧过程、衰败的过程、跳水动作、慢跑锻炼）；2~14 字白话自然，禁符号，禁「某X」槽，禁以「地」结尾。
2. **本来就是事物/地点/时间的**（乡下/晚上/角落/段落/楼下 类）→ **保持不动**（它们无动词歧义）。
3. 拿不准不动（保守）。改写优先常用自然说法，避免生造（如「退休这件事」这种可接受但「上升的这种现象」这种臃肿不要）。

## 铁律

未修义逐字节保留；条数顺序冻结；词性标记不变；其他词性义一律不碰；只准写这一个输出文件，严禁触碰 webapp/。

## 自查

输出 JSON 可解析；只含输入词；未修义逐字节一致；修改的名词义无某、无地结尾、事物感明确。
