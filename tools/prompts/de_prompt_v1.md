# 副词带地判定 + vi 动作感任务（de / vi）· 规范提示词 v1（禁改）

两个批次同规范（都遵循 AI交接/11 中文工程总规范，先读它）：

## 批 de_NN（副词带地）——用户需求：副词一眼可辨

输入 `{"词": ["全部义项"]}`（该词有不带「地」的副词义）。逐条判定：

1. **方式/状态类副词**（描述动作怎样进行，加「地」语法自然）：补「地」。
   例：`adv. 故意` → `adv. 故意地`；`adv. 勉强` → `adv. 勉强地`；`adv. 特意` → `adv. 特意地`。
2. **短语型功能副词**（在/往/以/由此/再一次/这样一来/在楼上 类——加地是病句）：**保持不动**（它们靠在/往/再 等虚词开头自明为副词性）。
3. **1~2 字程度/关联/时间功能词**（很/太/也/都/还/再/然后/大约/不久——加地病句或语义畸变）：**保持不动**。
4. **时间/频率可兼容的**（经常/偶尔/渐渐/逐渐/慢慢 类，加地语法自然）：补「地」。
5. 拿不准加地是否自然 → 不动（保守）。读音会变（地读 dì 与「的」区分是既有声音层设计），无需你管。

只输出有修改的词（完整 m 数组）；铁律：未修义逐字节保留、条数顺序冻结、2~14 字、禁符号、其余词性义一律不碰。

## 批 vi_NN（不及物动词动作感）——用户需求：与名词拉开区分

输入 `{"词": ["全部义项"]}`（该词有短的、无槽的 vi 义，或 vi 义文本与库内某名词义相同）。逐条判定：

1. **与名词容易混淆的**（中文动名同形：上升/下降/退休/增加 类，或文本与库内名词义完全相同）：改写成带动作感的动词短语——趋向补语（往上升、往下落、退下来、走出来）、连动（去旅行、哭起来）或换明确动词（入学→去上学）。保持无「某」槽（vi 不带宾语，这是定稿形态）、2~14 字白话。
2. **本身就是明确动词的**（躺、说谎、游泳、站立、流泪——中文里无名词歧义）：**保持不动**。
3. 改写不得引入宾语槽、不得改词性标记；拿不准不动。

只输出有修改的词；铁律同上。

## 交付自查

输出 JSON 可解析；只含输入词；未修义逐字节一致；de 批的修改义必须以「地」结尾；vi 批的修改义不得含「某」。
