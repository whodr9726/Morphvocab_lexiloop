# 介词动词拆分任务（vpsp）· 规范提示词 v1（唯一权威版，禁改）

你是词条重构员。把「混合词条」（vp. 介词动词义 + 其他词性义挤在一起）拆成：母词（只剩其他词性义）+ 若干独立新词条（vp 义按介词分组，各成新词）。

## 输入输出

- 输入：`<项目根>\tools\v2_batches\vpsp_NN.json`，格式：
  `{"母词": {"m": ["现全部义项"], "vp": {"义项下标": "英语介词", ...}}, ...}`
- 输出：`<项目根>\tools\v2_out\vpsp_NN.json`，格式：
  ```json
  {"母词": {
     "new_m": ["母词保留的义项（逐字节）"],
     "vp_entries": [
       {"form": "母词 介词", "m": ["该介词的 vp 义项（逐字节）"], "tier": "B1",
        "chunks": [["块","块义"], ...]}
     ]
   }, ...}
  ```
- 只准写这一个输出文件，严禁触碰 `webapp/` 目录任何文件。

## 拆分铁律

1. **逐字节保留**：new_m 里的每条 = 原 m 里去掉 vp. 开头的义项后，其余义项原文原序；vp_entries 里的每条 vp 义 = 原 m 里的 vp. 义原文。一条不许删、不许改字、不许调序。
2. **按介词分组**：同一母词的 vp 义按 vp 表里的介词分组，每个不同介词一个新词条；form = 母词 + 一个空格 + 介词（abide + by → "abide by"）。
3. **tier 常用度档位**（新词条插学习顺序用）：A1 日常高频 / A2 常用社会生活 / B1 中频 / B2 中高频书面 / C1 学术 / C2 专业文学 / D 生僻。按该 vp 搭配的真实使用频率判，拿不准取更低频档。
4. **chunks 拆块**（组合拼写用，先读规范 `tools/prompts/ckm_prompt_v2.md`）：块拼接必须逐字符还原 form（含空格）；词干部分按词根词缀规则拆（整词优先，无构词单位则整词一块）；介词独立一块、前面带空格（"abide by" → [["abide","遵守"],[" by","依据"]] 类似形态）；块数 1~4；多块每块带 0~6 字纯中文块义；单块允许空块义。
5. 母词拆完 new_m 为空数组不可能出现（输入都是混合词）；若你发现某词条 vp 表与 m 数组对不上（下标越界等），该词按原样放进 new_m 并在输出同级加 `"_note": "词名: 问题描述"`，不要猜。

## 交付自查

- 输出 JSON 可解析；每词 vp_entries 的义项并集 == 原 vp 义全集；new_m == 原义 − vp 义；chunks 拼接 == form；tier 枚举合法。
