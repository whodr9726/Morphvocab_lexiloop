## 与纯音节制的差异

| 项 | 纯音节制（已废止） | 词根词缀制（现行） |
|---|---|---|
| 切分依据 | 朗读音节（an+throp+olo+gy） | 构词单位（anthropo+logy） |
| 无构词单位的词 | 仍按音节切 | **整词单块**（carp） |
| 块义 | 无 | **每块带大致中文义**（un=否定） |
| 数据结构 | `{词: ["块",...]}` | `{词: [["块","义"],...]}` |

## 拆块规则摘要

1. 拼接逐字符还原原词 = 唯一硬裁判（含大小写/连字符/空格/缩写点）。
2. 整词优先：`un+precedent+ed`、`predict+ion`（剩余部分是同源可见词则不再细拆）。
3. 屈折后缀必切：`stop+ped`、`mak+ing`、`word+s`。
4. 常见派生后缀/前缀切出（清单见提示词文件）。
5. 可懂性优先于穷尽拆解：`content` 不拆 `con+tent`（误导），无构词单位的词整词单块。
6. 块数 1~4；超限从构词层级最浅边界合并（`inter+nation+al+ization`）。
7. 连字符/空格随块：`mother + -in + -law`；`boarding + " school"`。
8. 单块整词块义为空串；多块词每块 0~6 字纯中文块义（前缀/后缀=语法义，词根=核心义）。

## 下游联动（v6.19，本次一起上线）

- `chunk_map.js` 数据结构升级为 `[[块,义],...]` 对 → `?v` 递增。
- `splitWordChunks()` 取块改 `c[0]`（组合拼写字母块 tile 不变）。
- **纠错展示分解显示（用户新需求）**：拼错/不记得后的正确答案区，命中词表且多块的词，按块分行显示、每块下方一行块义（`fb-chunks` 样式）；单块/未命中词维持原大字单词。仅词无空格时查表（vp 词 "abide by" 整体显示，不分解）。
- 块义**只显示不朗读**（无音频成本）；三件套（大字/词性/释义）语义保留，分解视图替代大字单词位。

## 质量红线（批次校验器 `tools/ckm_check.js` 强制）

- 拼接还原失败 / 块数越界（1~4）/ 空块 / 二元组格式错 / 覆盖不齐（对输入词集合）→ 整批打回重派。
- 合并时三重校验（拼接还原/块数/全词覆盖）沿用 `tools/v2_chk_merge2.py`。
