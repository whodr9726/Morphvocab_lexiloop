# 中文工程总规范（2026-10-07 用户定稿，词义库唯一权威根规范）

> 本文是词义工程的**根规范**：tools/prompts/ 下各任务提示词（aud/trim/dup/qa/loss/slot）是它在具体任务上的投影，冲突时以本文为准。用户方法论：**只背意思不背语法，通过释义形态转译达到几乎完全正确的运用**。

## 一、义项结构（每元素一个义项）

1. `m` = 字符串数组，每元素 `"词性. 释义"`，**一条一个意思**，按使用频率降序、跨词性交叉。
2. **一条释义念出来必须是干净的一个意思**：
   - ❌ 逗号挤义：`有教育意义的，长见识的`（pretty 案）
   - ❌ 无分隔粘连：`长见识的有教育意义`（instructive 案）、`其实说实在的`（actually 案）、`客观事实上实际`（physically 案）
   - ❌ 半截语：`确实很`——很什么？悬空不算完整释义（really 案）
3. 并列规则：同义两段只留最常用一段；两个不同义拆成相邻两条；同一动作的不同对象/语境用「或」连接（`戳穿某物或撬开某门`）合法。
4. 每条 2~14 字口语白话，像给朋友解释；禁符号 `( ) （ ） [ ] 【 】 … ‥ = / 、 ; ；`；同条内确需并列用中文逗号（仅限互补，同义禁止）。

## 二、形态转译（词性靠释义形态承载，不加语法标记）

| 词性 | 释义形态 | 例 |
|---|---|---|
| 及物动词 | 裸宾语槽：动词+某/某人/某物/某事/做某事（双槽「某人某物」合法） | 说服某人、拿走某物 |
| 纯不及物动词 | 自足动作无槽 | 咳嗽、逃跑 |
| 介词动词 vp. | 中文介词引出（向/到/对/给/为/与），英文呈现"动词 介词"整体 | abide by 遵守某规则 |
| 形容词 | 永远带「的」（5 条限定词义合法例外：every 每一个等） | 吝啬的 |
| 方式副词 | 带「地」；**功能副词不带地**（很/也/经常/随后，语言学正确） | 迅速地 / 经常 |
| 名词 | 事物化裸名词短语，**禁止「某X」槽形态** | 退休生活（非「某规范」） |

## 三、跨词消歧（听中文写词不歧义）

不同词的释义文本不得完全相同（在两者可能同场考核时）：把区别融进各自文字（prejudice=先入为主的偏见 / bias=有倾向的偏袒）。英式美式拼写变体（licence/license）、一方生僻不同场者可保留同文。

## 四、义项完整性

词的常用词性义不得缺失（v1→v2 丢义已修复 61+17 词：petition 补 v.向某人请愿、forecast 补 n.预报）；义项条数与顺序是定稿工程，任何修复批次：**未修义逐字节保留、条数冻结（拆分类任务最多 +1）、顺序除拆分插原位外不变**。

## 五、声音层（TTS 只换读法，不改显示）

- 音色恒为小晓（zh-CN-XiaoxiaoNeural）；释义文本变更 → 增量重生成（未改义零成本复用）。
