# 学习调度规范：常用词优先 + 出错词退出（2026-10-05 用户定稿，AI 每日必查）

> 本文件是学习调度的**唯一权威规范**。AI 在每次「启动」和「终止」时必须执行第四节的检查清单。
> 用户核心方法论：**只背意思不背语法，通过释义形态转译达到正确运用；常用词先学，生僻词靠后。**

## 一、常用词优先机制（已实装，2026-10-03/04）

1. **七档体系**：A1 日常高频 / A2 常用社会生活 / B1 中频 / B2 中高频书面 / C1 学术 / C2 专业文学 / D 生僻。
2. **全库打分沉淀**：`tools/v2_out/rank_01~14.json`（未学段）+ `rank_15~20.json`（已学段，evict2_fill 用）。切批/校验器 `tools/rank_check.js`，规范 `tools/prompts/rank_prompt_v1.md`。
3. **数组即顺序**：ielts.js 未学段按 A1→D 稳定排序（同档保持库内原序）；autoSettleNew 每天复习清零后从 newCursor 起顺取 200 词 = 常用优先自动推进；todayNew 防手动回填与自动划入叠加。
4. **重排合并器**：`tools/rank_merge.py`（含不变量断言：前段逐字节不动、词集合不变、进度键全在册）。备份 `ielts.js.bak-preRank-*`。
5. **有效性证据**（2026-10-05 联网核实）：最高频 2000~3000 词族覆盖一般文本 70~90%（Dang 2022, Language Teaching Research）；间隔重复对长期记忆提升显著（Cepeda 2008 等）。

## 二、出错词退出规则（用户 10-04 定稿、10-05 澄清）

- **判据**（用户 10-04 定义）：`wrong ≥ 3 且 wrong > right`（与页面 🔴 频繁出错标签同款）。实测执行中 62% 为 C/D 档生僻词，与"踢生僻"意图吻合。
- **⚠️ 踢出不是常设自动机制**——只在用户明示授权时执行，AI 不得自作主张踢任何词（10-05 教训：把一次性判据说成"踢出线"，用户纠正：undertaking/deprive 等 C1 学术词属正常攻克，不该踢）。
- **执行工具**：`tools/evict_apply.py --dry/--apply`（测算/执行）；`tools/evict2_fill.py`（含 A1 等量回填版）。操作 = 删进度 → 按档位归位未学段同档末尾 → （可选）等量 A1 回填 → 备份 → rev+100 → 用户刷新。
- **已执行记录**：2026-10-04 两批共 352 词（103+249），名单 `tools/v2_out/evicted_words*.json`。

## 三、动学习序/进度的红线（每次必须全走）

1. 先备份 state.json + ielts.js（.bak-<操作名>-<日期>）
2. 断言三件套：数组已学前缀 == 进度键集合、进度孤儿键 = 0、词数守恒
3. 账本 rev+100，用户刷新后生效
4. 新增词条（如 vp 拆分类）必须同批按档位插入未学段同档末尾，禁止插到已学段

## 四、每日检查清单（AI 必查，结果向用户报告）

**「启动」时：**
1. 读账本报任务数：词/短语/介词的到期与额度（表格）
2. **队列健康**：到期词头部错词 top5 + 档位——正常攻克（对错各半）与积重难返（错远多于对）分开表述
3. **学习序抽查**：newCursor 后 10 词应全为 A 档常用词；异常 = 排序被破坏，回查合并记录
4. 短语/介词欠账天数：≥3 天升级提醒并询问是否调整策略（而不是反复无效提醒）

**「终止」时：**
1. 战报 + 正确率趋势：连续 3 天 <60% 时建议用户调低每日量
2. **越线词统计（只报告不行动）**：wrong≥3 且 wrong>right 的词数、档位构成、头部名单——由用户决定是否踢出
3. autoSettleNew 核验：todayNew 应 = 200（当天有手动回填除外）；划入词应为学习序头部档位
4. banner 写明日任务（**只准 banner + setProgress，严禁数量字段** B13）
